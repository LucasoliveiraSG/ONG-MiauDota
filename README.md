## **OBJETIVO DO PROJETO**
<div align= justify>
O objetivo deste projeto é aplicar na prática os conhecimentos teóricos e práticos adquiridos ao longo da disciplina no desenvolvimento de uma interface web funcional. A escolha por uma ONG voltada à causa animal justifica-se pela relevância social do tema e pela oportunidade de explorar recursos do front-end em um cenário de utilidade pública, promovendo a visibilidade de iniciativas não governamentais sem fins lucrativos.
</div>

## **PAGINAS DE APLICAÇÃO**
<div align= justify>
A aplicação web é composta por 4 páginas estruturadas de forma intuitiva para garantir uma boa experiência de navegação.

1. **Início (`index.html`):**
   * **Propósito:** Apresentação inicial e porta de entrada da instituição.
   * **Conteúdo:** Visão geral sobre a MiauDota, seções explicativas sobre a importância da adoção e o fluxo simplificado de como adotar um felino através da plataforma.

2. **Sobre A MiauDota (`sobre.html`):**
   * **Propósito:** Institucional, transparência e engajamento da comunidade.
   * **Conteúdo:** História fictícia da ONG, linha do tempo interativa com a trajetória da instituição, missão, visão e valores. Inclui métricas e indicadores de impacto (gatos resgatados, adotados e castrados), apresentação da equipe técnica (incluindo o corpo veterinário) e orientações sobre destinação de doações e trabalho voluntário.

3. **Adoção (`adocao.html`):**
   * **Propósito:** Vitrine digital dos animais e pré-triagem de adotantes.
   * **Conteúdo:** Banner motivacional, questionário de autoavaliação para conscientização da posse responsável, galeria interativa dos gatos disponíveis com filtros de busca, guia detalhado do processo de adoção, direitos e deveres do tutor, seção de dúvidas frequentes (FAQ) e formulário de manifestação de interesse.

4. **Contato (`contato.html`):**
   * **Propósito:** Central de atendimento e suporte aos visitantes.
   * **Conteúdo:** Canais oficiais de comunicação (simulação de e-mail, redes sociais e WhatsApp), formulário integrado para envio de mensagens diretas, orientações para cadastramento de lares temporários ou voluntariado, localização geográfica, horários e regras para visitação presencial.
</div>

## **FUNCIONALIDADES EM JAVASCRIPT (JS)**
<div align= justify>
O projeto conta com interatividade dinâmica utilizando JavaScript puro (Vanilla JS), destacando as seguintes funcionalidades implementadas pela equipe:

1. **Validação Inteligente e Contador de Caracteres no Formulário:**
   * **Descrição:** O script monitora o preenchimento dos campos em tempo real, exibindo um contador dinâmico de caracteres digitados abaixo da mensagem. 
   * **Regras de Validação:** Ao acionar o envio (`submit`), o código intercepta a ação (`preventDefault()`), limpa espaços extras, executa checagens de integridade (nome com no mínimo 3 caracteres, e-mail contendo `@`, seleção obrigatória de assunto e mensagem com ao menos 10 caracteres) e fornece feedback visual imediato ao usuário (erros em destaque ou alerta verde de sucesso simulado com limpeza automática do formulário).

2. **Alternância de Visibilidade de Elementos (Toggle / FAQ):**
   * **Descrição:** Sistema interativo que manipula o DOM para alternar o estado de elementos na tela. Ao realizar uma ação de clique, o script exibe textos que estavam ocultos ou os recolhe caso já estejam visíveis, otimizando o espaço da interface e melhorando a experiência do usuário (UX).
</div>

## **INSTRUÇÃO DE EXECUÇÃO**
<div align= justify>
Para visualizar e executar o projeto em sua máquina local, siga os passos abaixo:

### Pré-requisitos
* Um navegador web moderno (Google Chrome, Firefox, Edge ou Safari).
* Editor de código **VS Code** (recomendado).
* Extensão **Live Server** para VS Code (opcional, mas recomendada).

### Passo a Passo

1. **Obter os arquivos do projeto:**
   Clone o repositório utilizando o Git no terminal:
   ```bash
   git clone [https://github.com/seu-usuario/miau-dota.git](https://github.com/seu-usuario/miau-dota.git)


Também, como alternativa, faça o download do arquivo ZIP do repositório no GitHub e extraia a pasta em seu computador

1. Abrir a pasta do projeto:
Abra o VS Code, vá em Arquivo > Abrir Pasta... (File > Open Folder...) e selecione a pasta do projeto MiauDota.

2. Executar no Navegador:

Opção 1 (Com Live Server): No VS Code, clique com o botão direito no arquivo index.html e selecione "Open with Live Server".

Opção 2 (Direta): Abra a pasta do projeto no seu computador e dê dois cliques no arquivo index.html para abri-lo diretamente no seu navegador padrão.
